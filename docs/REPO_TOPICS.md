## Short repository description

```text
Safety-aware AI advisor for Arch Linux Btrfs installations with deterministic diagnostics, command risk classification and optional OpenAI-compatible explanations.
```

## Longer repository description

```text
AI-assisted Arch Linux Btrfs installation advisor that collects read-only diagnostics, generates structured installation plans, classifies command risk and optionally explains plans through a validated OpenAI-compatible LLM boundary.
```

## Notes

The project is intended as an AI Engineering portfolio case study and should be presented as a human-in-the-loop advisor, not an autonomous installer.

Recommended positioning:

```text
Deterministic safety first. Optional LLM explanation second.
```
